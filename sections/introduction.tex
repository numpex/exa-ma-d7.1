\subsection{Purpose and Scope of the Document}
\label{sec:purpose}


Exa-MA develops numerical methods and scientific software for
exascale computing within PEPR NumPEx. This edition presents work
reported in 2026 and retains earlier results where they provide a
baseline. The mega-deliverable includes the D7.1 benchmarking report
(\cref{chap:methodology,chap:applications}) and assembles the related
project deliverables.

\subsection{Structure of the Document}
\label{sec:structure}

The work package chapters explain the methods. The software fiches
identify the implementations and versions. Application fiches describe
the test problems and report the available measurements. For example,
the WP3 Composyx advance links to the software fiche and the
heterogeneous-diffusion study
(\cref{tab:advance:WP3-A2026-5,sec:Composyx:software,sec:app:specs:app-composyx-diffusion}).
\Cref{tab:framework-application-map,tab:v3-benchmark-registry} provide
entry points from the software and benchmark catalogues.
