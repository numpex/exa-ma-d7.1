\subsection{Software summary}
\label{sec:HPDDM:summary}

HPDDM (High-Performance unified framework for Domain Decomposition Methods) is a library of
advanced Krylov methods and multilevel domain decomposition methods, used as preconditioners, designed for high-performace computing.
The available Krylov methods include CG, block CG, GMRES, and block GMRES.
The available domain decomposition methods include one- and multi-level restricted additive Schwarz (RAS) methods.
The efficiency of these methods has been shown on elliptic PDEs such as the scalar diffusion equation, the linear elasticity equations,
or the Helmhotz equation for wave propagation.
The library can be used through various software for scientific computing:
PETSc, SLEPc, FreeFEM, Feel++, or HTOOL.

\subsection{Purpose}
\label{sec:HPDDM:purpose}

HPDDM aims at providing the scientific community a set of robust and efficient domain decomposition methods
to solve linear systems in parallel.

\subsection{Developments in 2026}
\label{sec:HPDDM:2026}

\paragraph{PETSc-native CPU/CUDA backend.}
The \texttt{PCHPDDM} integration in HPDDM 2.4.0 and PETSc 3.25 uses PETSc
\texttt{Vec} and \texttt{Mat} objects for the partition of unity, deflation
vectors and coarse-correction work vectors.
The corresponding operations use PETSc's CPU or CUDA implementations,
with storage chosen consistently with the input operators.
The implementation is documented by
\href{https://github.com/hpddm/hpddm/pull/148}{HPDDM PR \#148} and
\href{https://gitlab.com/petsc/petsc/-/merge_requests/9136}{PETSc MR !9136}.

The supporting dense-matrix interfaces
\texttt{MatCreateDenseWithMemType()} and
\texttt{MatDenseReplaceArrayWithMemType()} were added in
\href{https://gitlab.com/petsc/petsc/-/merge_requests/9117}{PETSc MR !9117};
their adoption in HPDDM is recorded in
\href{https://github.com/hpddm/hpddm/pull/146}{PR \#146}.
\href{https://gitlab.com/petsc/petsc/-/merge_requests/9130}{PETSc MR !9130}
adds \texttt{MatDiagonalScale()} for sequential CUDA/HIP dense matrices.
The HPDDM backend described here targets CUDA; HIP support in an individual
PETSc operation does not establish support for the complete HPDDM path.

The numerical method is unchanged. Coarse-operator assembly and
factorization remain on the host, and the deflation implementation still
contains host accesses during application.
Performance evaluation must therefore account for host work and transfers
during both setup and solve. A device-resident coarse operator and Kokkos
support remain development objectives.

\paragraph{Subdomains shared by several MPI processes.}
A separate, unreleased prototype groups the processes of a subdomain in a
sub-communicator, enabling parallel direct solvers for local problems.
The processes contribute collectively to the coarse operator, with assembly
coordinated by a leader; \texttt{PCGASM} provides the one-level smoother.
The prototype is restricted to two levels and excludes block splitting,
harmonic overlap, \texttt{-pc\_hpddm\_levels\_1\_st\_pc\_type mat}, and
Schur-complement preconditioning.
Its current validation uses a local driver; regression tests of the
one-subdomain-per-process path do not validate the new shared-subdomain path.
A versioned implementation reference and a registered test are still needed.

\subsection{Application entry points}
\label{sec:HPDDM:apps}
Applications using or evaluating HPDDM domain decomposition preconditioning include:
\begin{itemize}
        \item Discrete Fracture Networks (DFN) demonstrator: \cref{sec:app:specs:app-hpddm-dfn}; benchmark \texttt{BM-HPDDM-DFN-01}, with versioned application evidence pending.
        \item PETSc mixed-precision study: \cref{sec:app:specs:app-petsc-mixed-precision}; benchmark \texttt{BM-PETSC-MIXED-01}, with supported precision configurations and accuracy criteria to be specified.
        \item FreeFEM integration in mesh adaptation workflows (see Section~\ref{sec:app:specs:app-freefem-parmmg}).
        \item Feel++‑based demonstrators using HPDDM preconditioning (see Sections~\ref{sec:app:specs:app-feelpp-discr-1} and~\ref{sec:app:specs:app-feelpp-discr-2}).
\end{itemize}


\subsection{Mathematics}
\label{sec:HPDDM:mathematics}
\fullcite{dolean_introduction_2015} provides the mathematical foundation of the library, most importantly when it comes to the definition of parameter-robust preconditioner for symmetric positive definite systems.

\subsection{Relevant Publications}
\label{sec:HPDDM:publications}

Here is a list of relevant publications related to the software:
\begin{itemize}
\item \fullcite{jolivet_scalable_2013} presents a two-level domain decomposition preconditioner tested to solve elliptic problems in parallel with up to 22 billion unknowns in 2D and 2 billion unknowns in 3D.
\item \fullcite{jolivet_block_2016} presents block iterative methods and recycling strategies to solve linear systems with multiple right-hand sides and millions of unknwons while preserving a good scalability.
\item \fullcite{jolivet_ksphpddm_2021} presents KSPHPDDM (Krylov methods) and PCHPDDM (preconditioners) available in PETSc, when configured with HPDDM support.
\end{itemize}
