\subsection{Software summary}
\label{sec:Feelpp:summary}
\Feelpp (Finite Element Embedded Language and Library in C++) is an open-source
\Cpp{23} framework for the numerical solution of partial differential equations
and coupled ODE/PDE models. Its embedded variational language expresses Galerkin
methods close to their mathematical formulation, from continuous and
discontinuous finite elements to hybridizable discontinuous Galerkin and
spectral element methods~\cite{prudhomme_feel_2012}.
Python bindings through Pybind11 provide access to the library, toolboxes and
model order reduction workflows.

The framework has three complementary layers: the \textbf{core library} for
meshes, function spaces, forms and solvers; the \textbf{toolboxes} for reusable
single-physics and multiphysics models; and \textbf{model order reduction}
components for reduced basis, POD, empirical interpolation and related methods.
This structure supports both numerical-method development and scientific and
industrial applications.

\subsection{Purpose}
\label{sec:Feelpp:purpose}
\Feelpp connects mathematical formulation, parallel simulation and reduced-order
modeling in a common environment. It supports rapid prototyping of variational
models as well as reusable applications for research, engineering and teaching.
Typical applications include biomedical flows and heat transfer, building and
urban energy, high-field magnets, inverse problems, data assimilation and
uncertainty quantification. The catalogue's \emph{CPU Only} classification records
the benchmark coverage of this entry; it does not establish a hardware limit for
every dependency or application.

\paragraph{Solvers, meshing and data.}
PETSc provides linear and nonlinear solver infrastructure, with SLEPc for
sparse eigenvalue problems. The wider numerical environment includes Eigen and
Boost::ublas. Gmsh and MMG/ParMMG support mesh workflows, while exports serve
visualization tools such as ParaView and EnSight. The project documentation also
lists XDMF output.\footnote{\Feelpp project overview and features:
\url{https://github.com/feelpp/feelpp}.}
Checkpoint/restart permits selected simulations to resume from saved states.

\paragraph{Multiphysics and external coupling.}
The toolboxes cover fluid and solid mechanics, heat and conjugate heat transfer,
fluid--structure interaction, thermoelectricity, electromagnetics, and
level-set/multifluid models. Coupling with external solvers through
\textbf{preCICE is available}, as confirmed by the maintainer in the current
catalogue update. This complements native multiphysics coupling and the
Dymola/OpenModelica/FMU interface.

\paragraph{Software quality and distribution.}
GitHub Actions workflows build and test \Feelpp and support packaging,
container delivery and continuous benchmarking. CTest covers unit tests,
mathematical verification and application validation in sequential and parallel
settings; the test count depends on the configured build.
The catalogue records Debian, Ubuntu, Fedora, Spack and Guix-HPC packaging, and
Docker, Apptainer and Singularity containers. Installation instructions and
current release artifacts are available from the project documentation and
repository. CodeMeta metadata is provided in
\href{https://github.com/feelpp/feelpp/blob/develop/codemeta.json}{\texttt{codemeta.json}}.

\subsection{Mathematics}
\label{sec:Feelpp:mathematics}
The core supports Galerkin discretizations on one-, two- and three-dimensional
meshes, including high-order geometries and embedded curves or surfaces.
Finite element spaces may carry scalar, vector or matrix values. Representative
spaces include
\[
  L^2,\quad \mathbf{L}^2,\quad \mathbb{L}^2,\qquad
  H^1,\quad \mathbf{H}^1,\quad \mathbb{H}^1,\qquad
  \mathbf{H}(\mathrm{div}),\quad \mathbf{H}(\mathrm{curl}).
\]
Spatial discretization combines with time integration, mesh adaptation,
domain decomposition and error estimation. Reduced-order methods include
reduced basis constructions, POD, empirical interpolation, NIRB and
data-assimilation techniques such as GEIM/PBDW.
Support for single, double and quadruple precision, and complex values, depends
on the numerical component and backend.

\subsection{Relevant publications}
\label{sec:Feelpp:publications}
The references below describe the framework and selected applications. The
software archive is a dated reference, not a claim about the latest release.
\begin{itemize}
  \item \fullcite{prudhomme_feel_2012}. Embedded variational language,
    Galerkin methods, domain decomposition and fictitious-domain examples.
  \item \fullcite{prudhomme_feelppfeelpp_2024}. Archived software reference;
    current documentation is available at \url{https://docs.feelpp.org}.
  \item \fullcite{van_landeghem_mathematical_2024}. Mathematical and
    computational treatment of moving and colliding rigid bodies in a Newtonian fluid.
  \item \fullcite{saigre_model_2024}. Model order reduction and sensitivity
    analysis for heat transfer in the human eye.
  \item \fullcite{prudhomme_ktirio_2024}. City-energy simulations and their
    CI/CD workflows on EuroHPC systems.
  \item \fullcite{saigre_coupled_2024_abstract}. Coupled fluid dynamics and
    heat transfer for aqueous humor flow; the bibliography also records the
    associated manuscript~\cite{saigre_coupled_2024_paper}.
  \item \fullcite{palazzolo2023shape}. Shape optimization for rigid objects
    in Stokes flow; implementation at
    \url{https://feelpp.github.io/feelpp-shapo/shapo/index.html}.
\end{itemize}
