\subsection{Software summary}
\label{sec:FUnTiDES:summary}

FUnTiDES (Fast Unstructured Time Dynamic Equation Solver) is a portable CPU/GPU C++ library, built on Kokkos, which provides solvers for coupled acoustic, elastic and acousto-elastic waves. Spatial discretisation is based on the spectral element method (SEM) on structured and unstructured meshes, supplemented by a discontinuous Galerkin (DG) solver. The computational kernels incorporate several optimisation techniques (sum factorisation, MPI domain decomposition, explicit memory management) to simultaneously meet time and memory constraints, including when calculating of the gradient of the cost function in FWI. All functionalities are exposed via a Python interface (pybind11): the user can control the solvers and retrieve wavefields and seismograms without writing any C++ code, which makes the code accessible to users outside the development team.

\subsection{Mathematics}
\label{sec:FUnTiDES:mathematics}
 To be completed by the FUnTiDES developers.

FUntIDES solves numerically the second order wave equation for several types of media.
It uses the Spectral Element Method (SEm), Discontinuous Galerkin Method (DGm) and a coupling between both (DG-SEm) as space discretization, 
the discretization in time been done using a second order Leap-Frog scheme.

In the case of acoustic medium, we seek the scalar pressure \textit{p} such as:

\begin{equation}
  \label{eq:acoustic wave equation}
  \left\{
  \begin{array}{ll}
    {\displaystyle \frac{1}{c^2} \frac{\partial^2 p}{\partial t^2}(\mathbf{x},t) - \Delta{p(\mathbf{x},t)}} = f(\mathbf{x},t) & \mbox{in} \quad \Omega \times [0,T] \\[2ex]
    \alpha {\displaystyle \frac{\partial p}{\partial t}(\mathbf{x},t) + \frac{\partial p}{\partial n}(\mathbf{x},t)} = 0 & \mbox{on} \quad \partial \Omega \times [0,T] \\[2ex]
    p(\mathbf{x},0) = p_0(\mathbf{x}), \; {\displaystyle \frac{\partial p}{\partial t}}(\mathbf{x},0) = p_1(\mathbf{x}) & \mbox{in} \quad \Omega
  \end{array}
  \right.
\end{equation}
 where $c$ is the acoustic wave speed and $f$ the source term. As boundary condition the code allows for Dirichlet boundary for the top boundary of the domain and Absorbing Boundary Condition (ABC) everywhere else.

In the context of elastic medium, we seek for the displasment vector $\textbf{u}$ which satisfy: 

\begin{equation}
  \left\{
  \begin{array}{l}
    \rho {\displaystyle \frac{\partial^2 \mathbf{u}}{\partial t^2}} = \mathrm{div} \, (\underline{\underline{C}}(\underline{\underline{\epsilon}}(\mathbf{u}))) + \mathbf{f}, \quad \mbox{in } \Omega \times [0,T) \\[2ex]
    \alpha {\displaystyle \frac{\partial \mathbf{u}}{\partial t}} + (\underline{\underline{C}} (\underline{\underline{\epsilon}}(\mathbf{u}))) \mathbf{n} = 0, \quad \mbox{in } \partial \Omega \times [0,T) \\[2ex]
    \mathbf{u}(\mathbf{x},0) = \mathbf{u}_0, \; {\displaystyle \frac{\partial \mathbf{u}}{\partial t}} (\mathbf{x},0) = \mathbf{u}_1 \quad \mbox{in } \Omega 
  \end{array}
  \right.
\end{equation}

where  $\underline{\underline{C}}$ is the elasticity tensor which entries can vary depends if you are in an isotropic or anisotropic media
and $\underline{\underline{\epsilon}}$  is the strain tensor.

FUnTiDES is able to solve forward and inverse problem using Full WaveForm Inversion (FWI) algorithm.
