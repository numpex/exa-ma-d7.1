\chapter{Software Frameworks (D1.1, D2.2--D6.2)}
\label{chap:software}

The fiches describe the software developed or used in Exa-MA and its
role in the work packages. \Cref{tab:framework-application-map} links
each framework to its applications. The fiches include catalogue architecture categories and benchmark flags.
Campaign configurations and measurements appear in the application fiches
and benchmark index
(\cref{chap:applications,tab:v3-benchmark-registry}).

\section{Frameworks, Applications and Work Packages}
\label{sec:framework-application-map}

Table~\ref{tab:framework-application-map} provides clickable links from each
framework fiche to its application specifications and WP chapters. It is
generated from the shared catalogue's \emph{Frameworks} and \emph{Applications}
tabs. Applications sharing a framework, WP set and stage are grouped together.
An application can appear under several frameworks.

Only frameworks enabled for this chapter and explicit application associations
are shown. \emph{Framework scope only} identifies catalogue WP topics without a
registered application association. The listed stages describe application
maturity. \Cref{tab:v3-benchmark-registry} reports benchmark progress.

For application types and evaluation methodology, see
Chapter~\ref{chap:methodology}; for the full registry and application matrix,
see Sections~\ref{sec:v3-application-registry}
and~\ref{sec:v3-cross-wp-application-matrix}.
