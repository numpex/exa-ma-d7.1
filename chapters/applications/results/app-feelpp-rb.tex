\paragraph{Validation status.}
No run archive, machine specification or raw timing/error dataset was identified
that substantiates the numerical performance claims in the earlier RB narrative.
The Eye2Brain configuration is available, but this application has no

\paragraph{Acceptance of a future campaign.}
A campaign should pair a reproducible offline database with independent
full-order/reduced comparisons, separate online solve and reconstruction costs,
and report basis size, scientific errors, total offline cost and online speedup
at fixed accuracy. EIM/DEIM results require a matching implemented configuration
and raw run records; an operational catalogue status alone does not establish them.
