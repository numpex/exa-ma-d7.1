\Cref{fig:autorefine-exec-times} and \Cref{fig:autorefine-speedup} illustrate the multithreaded performance of the CGAL autorefinement algorithm for various mesh sizes using up to 64 threads.
As observed, the parallel efficiency is highly constrained.
While there is a slight decrease in execution time when moving from 1 to 2 or 4 threads, the speedup plateaus significantly below the optimal theoretical limit, achieving a maximum speedup of only ~1.5x to 2x on 16 threads.
This poor scaling suggests a high level of sequential overhead, data dependency, or thread contention during concurrent local mesh updates.

\Cref{fig:autorefine-algo-complexity}  illustrates the time complexity of the autorefinement algorithm.
The execution time exhibits a non-linear (convex) growth with respect to the initial grid size.
This behavior reflects the increasing computational cost associated with searching, verifying geometric properties, and maintaining the internal data structures as the mesh density increases.
