\subsection{Description of the benchmark}

A single export timer cannot distinguish cheaper field preparation from
faster writing. The November 2026 mini-app measures both without solving
a PDE. EnSight Gold writes vertex or cell samples for visualization;
native HDF5 preserves the mesh and original finite-element coefficients
for checkpoint/restart and analysis.

\subsection{Benchmarking methodology}

EnSight field registration (\texttt{add}) measures preparation, excluding
space and field setup. The save timer distinguishes geometry from field
packing and write. Geometry is written once for a static mesh and at
each tested frame for a moving mesh. Timings use the maximum across MPI
ranks; warm values summarize the later frames by median. Native HDF5
times mesh and field save and exact same-partition reload separately.
Uninstrumented repeats measure time; separate Darshan runs check which
ranks actually write.

\subsection{Input/Output Dataset Description}

The inputs are prepartitioned tetrahedral cubes (8.43--127.52 million
cells), with matching \texttt{.json} and \texttt{.h5} files. The campaign
covers continuous nodal P1--P3 and DG cell P0--P3 on linear geometry,
with scalar, vector and tensor fields. Gaya/NFS and Discoverer/Lustre
measurements are not pooled. Run identities, output sizes, samples
and verification are in the \texttt{apps-feelpp} evidence archive
\nolinkurl{docs/analysis/io-evidence-20261122}.
