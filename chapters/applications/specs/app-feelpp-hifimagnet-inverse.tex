\subsection{Description of the benchmark}
Inverse application: estimate nonlinear electrical-conductivity, thermal-conductivity, contact and cooling parameters from voltage-drop, temperature and optional magnetic-field observations collected at several imposed-total-current operating points.
\paragraph{Specification boundary.}
The output is a calibrated parameter vector or field and reconstructed
observables, not an operating control.  \texttt{BM-FEEL-HIFI-INV-01} is a
proposed verification/scalability record based on Taylor-gradient tests,
parameter recovery and observation misfit.
\paragraph{Planned contribution.} Review the objective below with the case owner; choose parameter bounds, observation uncertainties and regularization before implementing the optimization workflow.


\paragraph{Proposed mathematical problem.}
For experiments $e=1,\ldots,N_e$ at fixed imposed currents, solve the shared
forward equations in \Cref{sec:app:feelpp:shared-thermoelectric} for
$u_e(p)=(T_e,V_e,\Delta V_e)$. Estimate material, contact or cooling parameters
by
\[
 \min_{p_{\min}\le p\le p_{\max}}
 \frac12\sum_e\|W_e(H_e(u_e(p))-y_e)\|_2^2
 +\frac{\alpha}{2}\|L(p-p_{\rm ref})\|_2^2.
\]
Here $y_e$ contains voltage-drop and temperature observations, optionally
magnetic measurements only when the operator $\mathcal B$ is supplied.
$W_e$ scales observables by their stated uncertainty/units; $L$ and $\alpha$
define the regularization. Parameter units, bounds, reference values,
observation positions, noise model and units are input data still to be
selected; no numerical values or identifiability claim are assumed.

\paragraph{Verification and delivery plan.}
Begin with a manufactured synthetic parameter-recovery case and an independent
forward mesh or controlled perturbation to avoid validating only a repeated
identical solve. Separate noise-free recovery, noisy data and regularization
sensitivity. Verify gradients with a directional Taylor test: the
first-order-corrected objective remainder should decrease quadratically until
solver error/roundoff dominates. Inspect sensitivity rank and parameter
correlation before treating a low misfit as unique recovery.
The forward model is delivered by CFG/JSON; optimizer, observation and
adjoint/gradient orchestration are additional workflow components and remain
planned. TAO/ROM capabilities in the wider framework do not establish an
implemented adapter for this case. Report objective terms, projected-gradient
or bound-stationarity measure, PDE solves, errors and time-to-inference.

\subsection{Benchmarking methodology}


\begin{description}
  \item[Method-Algorithm WP1:] nonlinear thermo-electric finite elements, coupled PDE-scalar formulation, integral total-current boundary condition
  \item[Method-Algorithm WP2:] ROM, hyper-reduction, surrogate models, FOM/ROM switching for repeated forward and adjoint evaluations
  \item[Method-Algorithm WP3:] nonlinear block solvers, adjoint linear solves, PETSc/HPDDM preconditioning
  \item[Method-Algorithm WP4:] PDE-constrained parameter inversion: weighted multi-experiment data misfit plus regularization; adjoint gradients; nonlinear least squares; parameter bounds; optional Gauss-Newton/Hessian actions and identifiability analysis
  \item[Method-Algorithm WP6:] measurement-noise modelling, uncertainty propagation, ensemble inversion
  \item[Framework:] Feel++, PETSc/TAO, HPDDM
  \item[parallel\_framework:] MPI, Kokkos, GPU - HIP
  \item[Benchmark scope:] multi-node, multi-gpu, full-system, method-verification, solver-scaling, ensemble-mode
  \item[metrics:] Taylor-gradient-test, parameter-recovery-error, observation-misfit by observable, regularization contribution, identifiability, time-to-inference, PDE-solves-to-solution, TAO-iterations, strong-scalability, weak-scalability, experiment-throughput
\end{description}
\paragraph{Planned contribution.} Review the proposed protocol and select the case-specific tolerances and parameter values before implementation.
