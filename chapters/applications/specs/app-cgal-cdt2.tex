{WP1}{mini-app}
{Demonstrate weak and strong scalability of constrained Delaunay triangulation.}
{CGAL, Intel TBB}{brainstorming}
\subsection{Description of the benchmark}
This proposed test measures how CGAL constrained Delaunay triangulation
scales with thread count for planar inputs containing constrained segments.

\subsection{Benchmarking methodology}
\texttt{BM-CGAL-CDT2-01} would measure strong and weak scaling on a
single node using Intel TBB. The input series and constraints used to
check validity have yet to be specified.
