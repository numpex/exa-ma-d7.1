\label{sec:app:specs:app-feelpp-nlcrb}

\textbf{Status:} The \href{https://github.com/feelpp/nonlinearrb}{nonlinearrb}
workflows use Feel++ finite-element kernels. Native Feel++ runs on Gaya
provide full-order and hyper-reduction reference results for Burgers.

This demonstrator studies nonlinear compressive reduced-basis methods for parametric PDEs. The current method retains resolved Galerkin coordinates and reconstructs unresolved reduced coefficients through learned maps.

\subsection{Description of the benchmark}
\subsubsection{Current methodological contribution}
The work in Hassan Ballout's PhD develops nonlinear compressive reduced
bases and parameter-based recovery of unresolved coefficients. The local
Taylor analysis and the combined Galerkin/regression formulation are
reported in \cite{hal_05466017,hal_05143191} and summarized under WP2/T2.4
in \Cref{tab:advance:WP2-A2026-4}. Regression reconstructs unresolved
coefficients while a Galerkin solve determines the resolved unknowns;
this is distinct from an encoder--decoder correction to a full solution.
The implementation, including the DG Burgers testbed, is documented in
\Cref{sec:Feelpp:implementation-2026:nlrb}.


\subsubsection{Discrete model and reduced coordinates}
The current comparison uses a common DG-P0 Burgers full-order model. Let
$R_h(u^{n+1};u^n,\mu)=0$ denote its fully discrete residual. For a reduced
basis split into resolved and unresolved blocks, write
\[
 u_N=V_r a+V_u\,g(a,\mu).
\]
A learned regression map $g$ reconstructs unresolved coefficients; the resolved
coordinates $a$ are determined by a reduced Galerkin equation. This describes
compression of reduced coordinates, not an encoder--decoder correction of a
full solution. The combined Galerkin/regression and Taylor/Kolmogorov analyses
are reported in \cite{hal_05143191,hal_05466017}.

\subsection{Benchmarking methodology}
\paragraph{Comparison contract.}
Pin the external \href{https://github.com/feelpp/nonlinearrb}{nonlinearrb}
revision and case configuration. Compare the full-order model, POD-Galerkin,
least-squares Petrov--Galerkin, NLCRB and NLCRB++ at identical spatial/time
resolution and solver tolerances. Report the resolved and reconstructed
basis dimensions separately. EIM/ECSW hyper-reduction comparisons must identify
sample sets, weights and their additional approximation error.

The nonlinearrb testbed uses per-face Rusanov fluxes, a theta-method and
Newton solves. The measured native 2D comparison on Gaya uses a Cartesian
Godunov flux. Each comparison fixes the flux, source integration, time
grid and Newton stopping tests across the full-order and reduced models.
The frozen-wave-speed variant defines a separate discrete experiment.

\paragraph{Training and verification.}
Define parameter ranges and independent training, validation and held-out test
sets, with sampling seeds and immutable sample lists. Mesh/time refinement and
basis truncation, regression and hyper-reduction errors must be separated.
Measure relative state error and relevant outputs on the test set; report
worst-case and aggregate errors against the same full-order reference. Include
data generation, basis construction and regression training in offline cost;
include residual evaluation and nonlinear solves in online cost. Hardware,
batch size and synchronization are part of any CPU/GPU timing comparison.
No sample count, speedup target or GPU result is assigned without a run record.

\subsection{Input/Output Dataset Description}
Inputs are a pinned Burgers case, spatial/time grids, physical/parameter data,
full-order snapshots and explicit train/test partitions. Outputs include basis
and regression checkpoints, reduced operators/hyper-reduction samples,
state/output errors, residual and Newton histories, and separately recorded
offline/online timings. A reduced database is a versioned model artifact; it
is not a replacement for a mesh archive.
