\section{Benchmark index}
\label{sec:benchmark-index}

The index gives the stage reached by each campaign. Application
identifiers link to the fiches included in this collection.
\nolinkurl{data/benchmark-registry-v3.csv} records configurations, machine
and software details, baselines, measurements and data provenance.

For the reduced-basis Eye2Brain case, a versioned launch configuration is
available and validation is pending. The HPDDM discrete fracture network
figures come from the
\href{https://github.com/numpex/exa-ma-d7.1/blob/4473ef61ceec1773e7593385c92a87959438d92c/chapters/applications/specs/app-hpddm-dfn.tex}{2025 report (v1.93.0)};
the fiche records their provenance and the available execution details.
