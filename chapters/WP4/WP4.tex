\section{Objectives \& Context}
\label{sec:wp4:objectives}

WP4 develops inverse methods that combine observations with
large-scale simulations. Its tasks cover variational inversion
(T4.1), stochastic inversion (T4.2), observation design and error
models (T4.3), and the use and scheduling of models at several
fidelity levels (T4.4 and T4.5). The work draws on discretizations
from WP1, reduced models from WP2 and solvers from WP3.

\paragraph{Doctoral work.}
\href{https://theses.fr/s371978}{Hélène Hénon} studies multi-fidelity
variational data assimilation for ocean forecasts.
\href{https://theses.fr/s420025}{Mohamed Doumbouya}, enrolled since
October 2025, studies Bayesian sensor placement for ocean models.
The project personnel register records Bruno Latre's recruitment in
January 2026 under Hélène Barucq's supervision.

\section{Scientific Advances}

\subsection{Task 4.1 - Deterministic methods}
\label{sec:wp4:double-gyre}

In incremental four-dimensional variational data assimilation
(4D-Var), conjugate gradients solve the linear systems in the inner
loop. Hénon and Vidard construct a limited-memory spectral
preconditioner for the first outer iteration using a randomized
Nyström approximation. The sketch is assembled from independent
matrix--vector products. Using a lower-fidelity propagator in this
step reduces setup cost. Bounds based on Löwner ordering specify
when the resulting preconditioner improves the condition number of
the high-fidelity system.

The team also developed a hybrid sketch that enriches a random
subspace with low-fidelity applications and refines it with
high-fidelity products. The numerical study uses a two-dimensional
shallow-water model for double-gyre circulation. The
\href{https://exa-ma.numpex.fr/news/2026/20260119-21-ag.html}{January
assembly} showed a test on a $120\times120$ grid with a
single-precision low-fidelity model. Hénon and Vidard presented the
\href{https://hal.science/hal-05652339v1}{preconditioner} at the
Ocean Sciences Meeting in February.

\paragraph{Variational parameter identification (T4.1).}
The HiFiMagnet inverse-problem specification seeks material, contact and
cooling parameters from voltage, temperature and optional magnetic
observations at several imposed-current operating points. The formulation
combines a weighted multi-experiment data misfit with regularization,
subject to the thermo-electric state equations and parameter bounds.
Adjoint derivatives support optimization of the reduced objective.
The proposed verification uses Taylor-gradient tests, parameter
recovery and observation misfit
(\cref{sec:app:specs:app-feelpp-hifimagnet-inverse}).
The shared variational optimization interface is recorded in
\Cref{tab:advance:WP4-A2026-2} and implemented in WP7
(\Cref{sec:Feelpp:implementation-2026:tao}).

\subsection{Task 4.3 - Observation}
\label{sec:wp4:sensor-placement}

\href{https://arxiv.org/abs/2609.32282}{Doumbouya, Vidard and Zahm}
derive upper and lower bounds on expected information gain from
dimensional logarithmic Sobolev inequalities. The bounds use covariance
and Fisher information matrices. A conservative bound guides selection
for an entire observation network, and an incremental bound guides
sequential placement. The authors use model gradients to approximate
the Fisher terms during setup. Once the matrices are assembled, the
sensor search uses matrix operations with no further forward solves.

The \href{https://github.com/mohamed495/CBOED}{numerical experiments}
vary the nonlinearity in a viscous Burgers model. The bounds recover
the exact information gain in the linear-Gaussian case with jointly
Gaussian parameters and observations. Their tightness varies with the
nonlinearity of the forward model.

\section{Application Showcase}
\label{sec:wp4:applications}

\paragraph{Variational assimilation and sensor placement.}
The \hyperref[sec:wp4:double-gyre]{double-gyre study} tests low-fidelity
Nystr\"om preconditioning for the inner solve of incremental 4D-Var
on a two-dimensional shallow-water model. The
\hyperref[sec:wp4:sensor-placement]{viscous Burgers study} tests how
information-gain bounds guide sensor placement as the model's
nonlinearity varies.

\paragraph{HiFiMagnet parameter identification.}
The \hyperref[sec:app:specs:app-feelpp-hifimagnet-inverse]{HiFiMagnet
inverse-problem fiche} specifies which material, contact and cooling
parameters to identify from observations. The
\hyperref[sec:Feelpp:implementation-2026:tao]{Feel++ interface to PETSc TAO}
provides the optimization components. Derivative checks and parameter
recovery on the application are planned under \nolinkurl{BM-FEEL-HIFI-INV-01}.

\paragraph{Ensemble Kalman inversion.}
The \hyperref[sec:app:specs:app-eki]{EKI mini-app} proposes a simplified
wave-equation inverse problem in a geophysical setting. Its PETSc/GeoS
workflow specifies MPI ensemble execution, a manufactured-solution
test and a weak-scaling protocol under \nolinkurl{BM-EKI-01}.

\section{Software Framework Contributions}
\label{sec:wp4:software}
Feel++ implements the variational optimization interface over PETSc
TAO, with functional and variational-form tests
(\cref{sec:Feelpp:implementation-2026:tao}). WP5 uses the same
interface for optimal control. The proposed EKI mini-app uses PETSc
for ensemble execution and GeoS for its application setting.

\section{Benchmarks}
\label{sec:wp4:benchmarks}

The \hyperref[sec:wp4:double-gyre]{double-gyre test} uses a
$120\times120$ grid to evaluate a 4D-Var preconditioner with a
single-precision low-fidelity model. The
\hyperref[sec:wp4:sensor-placement]{sensor-placement study} uses
viscous Burgers cases to assess the tightness of information-gain
bounds as nonlinearity varies.

Two proposed protocols are recorded in the
\hyperref[tab:v3-benchmark-registry]{benchmark registry}. The
\hyperref[sec:app:specs:app-feelpp-hifimagnet-inverse]{HiFiMagnet
inversion benchmark} (\nolinkurl{BM-FEEL-HIFI-INV-01}) specifies
derivative checks and parameter recovery. The
\hyperref[sec:app:specs:app-eki]{ensemble Kalman inversion benchmark}
(\nolinkurl{BM-EKI-01}) specifies manufactured-solution verification
and ensemble weak scaling.

\section{Next steps}
\label{sec:wp4:roadmap}

For HiFiMagnet, the next step is to run the parameter-recovery and
derivative checks on the variational interface. For the ensemble Kalman
inversion mini-app, the development target is a forward solver and
inversion loop in PETSc and GeoS, followed by the tests in
\Cref{sec:app:specs:app-eki}.
